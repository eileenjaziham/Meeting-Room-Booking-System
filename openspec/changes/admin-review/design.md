## Context
多个负责人管理所有五间房；负责人自身预约按其师生身份处理。
## Goals / Non-Goals
工作台、学生审批、身份审核和台账四维筛选；不提供在线授权管理员或 P1 房间停用。
## Decisions
所有 admin.* 操作先查独立授权表。审批、取消和创建共用数据库锁，审批复核当前学生资格、人数和未开始状态。拒绝必填原因；只一次有效状态转换。存处理人、时间、原因及 audit_logs。
## Risks / Trade-offs
台账只向负责人返回个人联系方式；正式数据保留期限需业务确认。课程版本全量过滤，尚无分页。
## Migration Plan
运维先在服务端授权负责人；小程序管理入口根据 me.isAdmin 展示，但接口重新鉴权。
