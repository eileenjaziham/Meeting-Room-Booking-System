# Proposal
## Why
学生需要从“我的”查看本人资料、提交使用反馈，并识别当前版本。现有身份审核页面不能替代清晰的个人信息入口。
## What Changes
- “我的”增加个人信息与反馈中心入口，底部展示当前构建版本。
- 本人资料只读；反馈保存到数据库，支持本人查看和管理员回复。
## Capabilities
### New Capabilities
- `profile-and-feedback`: 本人资料入口、版本展示和私有反馈处理。
### Modified Capabilities
无。
## Impact
我的页面、个人信息/反馈页面、管理工作台、反馈SQL表与服务接口；保留已有预约和身份核验规则。
