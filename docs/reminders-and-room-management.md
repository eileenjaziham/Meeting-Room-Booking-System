# 日历、未读提醒与管理页整理

日历红点表示本人当日有待确认或成功预约，不代表未读。取消、拒绝、失效或结束后不再标记；同日多条仍只显示一个红点，辅助说明保留条数。展开月历、切月和返回首页均重新计算。

首页“我的预约”及个人中心以红点提示未读预约结果。审核通过、拒绝、待审核失效以及管理员/停用取消进入本人通知；查看结果或详情后提交已读回执，数据库保存，重复回执不重复修改。通知按账号隔离，管理员查看他人详情不能替他人消除未读。新功能启用前已处理的历史预约不会补造未读消息。

管理员首页“学生预约审核”及工作台“用户审核”“用户反馈”按实际待处理数量显示红点，处理后清除。首页可见时每30秒轻量刷新提醒和管理待办，不重新加载房间列表；离页/卸载停止，旧响应丢弃。返回首页及下拉刷新即时更新。

会议室管理保留选择→停用表单→预览确认→历史记录流程。五间房改为统一单行选择，编号、容量、设备、状态、箭头对齐；选中态校园蓝。日期纵向展开避免长日期挤压，起止时间并列，停用原因复用form-field，操作按钮铺满卡片，历史按状态、日期、原因、恢复信息分层。现有停用事务、版本预览、通知与解除规则未改。

检查包含数据库通知归属/已读持久化/失效去重、Page事件中的日历标记与红点清除、离页停止刷新及组件红点切换。源码布局预览覆盖320、440宽度的学生/管理员首页、个人中心及管理页各区段；未发现横向溢出、图片缺失或过小触控区域。预览是WXML/WXSS派生HTML，不能替代微信原生滚轮、键盘及真机验收。截图位于`artifacts/ui-review-20261123-103838/after-admin-rooms-440.png`等。

实际结果：完整86项测试通过，17页/10组件WCC/WCSC编译通过，7项OpenSpec严格校验通过；12组布局预览通过。本地后端已重启加载消息与提醒逻辑；云函数仅同步源码，未部署。
