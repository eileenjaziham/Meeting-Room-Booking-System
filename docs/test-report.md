## 限制与重现

Page宿主API和JSDOM模拟不等同真实微信渲染、原生picker、网络域名限制或真机测试。WCC/WCSC包版本较旧，独立编译可发现语法错误，不能证明所有设备上的视觉一致。本次另在真实微信开发者工具中观察到登录页和首页运行，并成功连接回环后端；未据此宣称全页面或真机验收通过。控制台保留的401为首次未登录时的接口响应，登录后首页数据加载成功。
