- 原型出现 7091 容量10人、7052 容量40人、设备屏幕等示例；**业务冲突**以需求 V1.1 为准，分别12人、35人，设备待核实。7060 容量保持未知。
- 原型时间刻度仅示意；按需求使用真实 08:00—22:00，并依数据库占用生成百分比红色片段，任意分钟不取整。
- 原型局部两行日历保留为默认可折叠视图，增加月份切换、今天和展开月历，以完成真实日期查询。
- 原型未给出登录、申请、我的预约及管理页面完整图层；沿用浅蓝背景、白色圆角卡片、同一字号层级，管理操作辅助绿色。
