# 校园会议室预约 UI 规范

依据 `.agents/skills/ui-ux-pro-max/SKILL.md` 的 Minimalism、触控反馈、对比度、表单反馈规则，结合现有 Pixso 结构及用户确认的校园蓝/白/浅蓝。Skill 生成的营销 Hero/CTA 和外链英文字体不适用于当前原生小程序，未采用；没有匹配的微信小程序 stack 数据，按通用移动端 UX 规则映射到 WXML/WXSS。

- 保留校园图片、校徽、首页结构、两项原生 TabBar、管理员首页及全部业务 API。
- 主色 #2563EB，文字 #24364B，辅助文字 #52647A，浅蓝底 #EDF4FC；管理/成功 #167348，待确认 #965B12，错误/拒绝 #B42337，取消/完成中性灰。
- 统一语义变量见 `miniprogram/styles/tokens.wxss`，不加载远程字体或大型组件库。
- 440×956 为参考，750rpx 自适应；触控区至少44px，内容可换行，表单与页面底部留安全区。
- 卡片24rpx圆角、1rpx细边框、统一轻阴影；字段16rpx圆角，按钮18rpx圆角。
- 图标沿用本地24×24线性SVG、1.7描边；原生TabBar按平台要求使用同源72px PNG。
- 按压仅改变背景/透明度，不缩放布局；120ms反馈，减少动态效果时关闭过渡。骨架屏静态显示，不闪烁。
- 状态同时显示文字与颜色，不将占用时间条当作唯一说明。保留12rpx细时间条及原有边界标签避让。
- 日期/时间保留五分钟刻度、08:00—22:00、含当天七个日期、当前北京时间之后及只选空闲段。14:30—17:50仍可选择；不改后端分钟精度。
- 普通加载/空状态/错误使用复用反馈组件；取消、审批、停用等高风险确认保留平台原生确认，以保持原有行为。
- 字段失焦校验，错误靠近字段，提交失败引导第一个错误项；保留已有草稿和幂等请求。

验收覆盖320/375/440宽度的组件布局、长文本、状态语义、表单事件、WCC/WCSC编译。渲染对比与原生设备验证分别记录，不能把HTML渲染预览称作真机截图。暗色主题不在本次范围，固定浅色；系统最大字号、横屏、真机键盘需人工复核。
